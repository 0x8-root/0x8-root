## Избранные проекты

### [FuelMap](https://github.com/Lux-8/FuelMap)
Полноценная веб-платформа для поиска и изучения информации о заправочных станциях.

- Backend на Python и FastAPI.
- REST API и работа с SQLite через SQLAlchemy.
- Интерактивная карта на JavaScript и Leaflet.
- Система регистрации, авторизации и пользовательских отчётов.
- Административная панель для управления данными.

### [AI-Coach](https://github.com/Lux-8/ai-coach)
Веб-приложение с ИИ для подготовки к ВПР и олимпиадам. Генерирует адаптивные задания с учётом предмета, класса и типа подготовки.

- Backend на FastAPI.
- Интеграция с Groq API.
- Разделение системных промптов и основной логики.
- Frontend на HTML, CSS и JavaScript.

### [System Analyzer](https://github.com/Lux-8/System-Analyzer-Lux-8)
Python-утилита для мониторинга и диагностики компьютера.

- Мониторинг CPU, RAM и дискового пространства.
- Анализ состояния системы.
- Очистка временных файлов.
- Работа с системными ресурсами через Python.

### [JARVIS](https://github.com/Lux-8/JARVIS)
Модульный голосовой ассистент на Python для управления компьютером и автоматизации повседневных действий.

- Разделение логики на независимые модули.
- Обработка голосовых запросов.
- Работа с системными командами.
- Возможность расширения набора команд.
