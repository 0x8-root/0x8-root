##  Избранные проекты

### [Lux8-console](https://github.com/Lux-8/Lux8-console)
Небольшая CLI-утилита на Python, имитирующая работу консоли.

### [FuelMap](https://github.com/Lux-8/FuelMap)
Интерактивная платформа с картой заправочных станций. Backend построен на FastAPI, frontend использует JavaScript и Leaflet. Проект включает работу с данными о станциях, пользовательские отчёты и систему авторизации.

### [JARVIS](https://github.com/Lux-8/JARVIS)
Модульный голосовой ассистент на Python для управления компьютером, выполнения команд и автоматизации повседневных задач.

### [AI-Coach](https://github.com/Lux-8/ai-coach)
ИИ-репетитор для подготовки к ВПР и олимпиадам. Backend на FastAPI, взаимодействие с языковой моделью через Groq API.

### [System Analyzer](https://github.com/Lux-8/System-Analyzer-Lux-8)
Утилита на Python для диагностики системы, мониторинга ресурсов компьютера и очистки временных файлов.

### [LAVA-hub](https://github.com/Lux-8/LAVA-hub)
Концепция геймифицированного календаря и трекера задач с системой прогресса, достижений и игровых механик. Проект находится на стадии проектирования и разработки MVP.
